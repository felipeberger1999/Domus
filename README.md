# Domus — App do morador/gestor + SGC (web)

Protótipo navegável do ecossistema **Domus**: app do **morador**, app do **gestor** e o **SGC** (sistema web), compartilhando os mesmos dados (mesma origem).

## Acesso (demo)
Abra a página, senha **`demo`** e use um dos atalhos de login:

- **Morador** — app do morador (cobranças, reservas, visitantes, entregas, finanças)
- **Gestor** — painel do gestor (aprovações, recebíveis, resultado contábil, assistente)
- **Gestor + Morador** — escolhe o perfil

No modo Gestor, toque em **"SGC completo"** para abrir o sistema web.
